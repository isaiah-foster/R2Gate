## Cloudflare API Gateway (Workers + R2 + Durable Objects)
**Summary:** A global API Gateway built on Cloudflare’s edge network that authenticates, validates, and rate-limits incoming requests before routing to protected backend APIs.

### Features
- JWT/mTLS authentication
- JSON Schema validation
- Edge-based rate limiting
- Cloudflare R2 logging
- Optional analytics dashboard

### Tech Stack
TypeScript • Cloudflare Workers • R2 • KV • Durable Objects • API Shield • FastAPI

### Key Concepts Demonstrated
- Edge computing architecture
- Zero-trust access design
- Network-layer security enforcement
- Cloudflare developer ecosystem
